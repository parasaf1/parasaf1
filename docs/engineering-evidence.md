# Engineering evidence and verification boundaries

This profile is designed to be visually engaging **without blurring the line between verified public information and private implementation**.

## What is public here

The public [Engineering Showcase](https://github.com/parasaf1/engineering-showcase) is the source of truth for selected, sanitized evidence about my work.

It may include:

- project summaries
- validated milestones
- selected technical highlights
- public-facing architecture snapshots
- selected recent updates that are safe to publish

## What remains private

I do **not** publish private source code, credentials, prompts, proprietary internal workflows, user data, personal records, or confidential business information through this profile README.

## Why this matters

I care about two things at the same time:

1. **showing real engineering work**
2. **keeping security, privacy and integrity intact**

That means I prefer documented, verifiable public evidence over inflated claims.

## Reading the profile correctly

- Visual cards and diagrams are **public conceptual views**, not full implementation disclosures.
- The recent activity panel samples public events; the contribution statistics and landscape use calendar counts visible to the automation. Neither represents all private development volume.
- Project status panels are generated from **sanitized public metadata**.
- Where something is still in progress, I label it as in progress.
